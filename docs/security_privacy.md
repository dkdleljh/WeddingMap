# 보안과 개인정보 가이드

## 1. 기본 원칙
- 필요한 최소 정보만 저장합니다.
- 비밀번호는 해시로만 저장합니다.
- 관리자 권한은 일반 사용자와 분리합니다.
- 입력값 검증을 기본값으로 둡니다.

## 2. 현재 적용된 보안 항목
- bcrypt 기반 비밀번호 해시
- JWT 토큰 발급
- 관리자와 사용자 계정 분리
- Pydantic 기반 입력 검증
- FastAPI 예외 기반 오류 처리

## 3. 개인정보 최소 수집 원칙
### 사용자
- 이메일
- 비밀번호 해시
- 닉네임
- 선택 입력: 선호 지역, 예산 범위, 예상 하객 수

### 문의
- 이름
- 전화번호
- 이메일 선택 입력
- 문의 내용

## 4. 추가로 필요한 보안 작업
- 관리자 API 인증 강제
- 토큰 재발급과 폐기 정책 강화
- 레이트 리밋
- 캡차 또는 스팸 방지
- XSS 필터링 강화
- CORS 운영 정책 세분화

## 5. 운영 시 주의사항
- 샘플 계정은 개발 환경에서만 사용
- 운영 환경의 비밀 값은 반드시 새로 발급
- 외부 키는 저장소에 직접 넣지 않기
- 로그에 개인정보를 남기지 않기
