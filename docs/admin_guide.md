# 관리자 가이드

## 1. 관리자 화면 목적
관리자 화면은 예식장 운영 정보, 가격, 리뷰, 문의, 수집 로그를 하나의 흐름으로 관리하기 위한 내부 도구입니다.

## 2. 화면 구성
- 대시보드
- 예식장 목록
- 예식장 상세 편집
- 가격 관리
- 리뷰 검수
- 문의 관리
- 수집 실행과 로그
- 감사 로그

## 3. 로그인과 권한
- 관리자 앱은 로그인 후 백엔드가 내려주는 `httpOnly` 세션 쿠키를 사용합니다.
- `/api/admin/*`, `/api/ingestion/*` 호출에는 브라우저가 세션 쿠키를 자동으로 포함합니다.
- 토큰이 없거나 만료되면 관리자 앱은 로그인 화면으로 되돌립니다.
- 개발용 기본 관리자 계정은 샘플 시드 기준 `admin@weddingmap.kr / AdminPassw0rd!` 입니다.

## 4. 운영 흐름
### 대시보드 확인
- 등록 예식장 수
- 운영 중 예식장 수
- 미검수 리뷰 수
- 문의 대기 건수
- 지역별 예식장 수

### 예식장 편집
- 이름, 주소, 설명, 전화번호, 홀 타입 수정
- 운영 여부 변경
- 공공예식장 여부 변경
- 신뢰도 등급 조정

### 가격 관리
- 항목명 수정
- 최소 금액, 최대 금액 수정
- 운영 메모 저장

### 리뷰 검수
- 승인
- 숨김
- 향후 신고 누적 기반 자동 숨김 규칙 추가 가능

### 문의 관리
- 접수됨
- 처리 중
- 처리 완료

### 수집 실행
- 공공데이터 수집 작업을 기록
- 최근 실행 로그 확인
- 실행 이력은 감사 로그와 별개로 수집 로그에 누적됩니다.

### 감사 로그
- 예식장 수정
- 가격 수정
- 리뷰 승인과 숨김
- 문의 상태 변경
- 향후 운영자 생성, 권한 변경, 병합 작업까지 확장할 수 있습니다.

## 5. 주의할 점
- 예식장 데이터 수정은 사용자 화면에 직접 영향을 주므로, 운영 메모와 검수 시점을 함께 관리하는 것을 권장합니다.
- 공공데이터와 운영자 입력이 충돌할 수 있으므로, 원천 출처를 반드시 확인해야 합니다.
- 운영 환경에서는 `secure=true`, 별도 관리자 도메인, 세션 회전 정책까지 함께 적용하는 것을 권장합니다.
