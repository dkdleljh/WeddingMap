# 프로그램 고도화 계획

## 1. 문서 목적
이 문서는 WeddingMap을 MVP에서 운영 확장 단계로 끌어올리기 위한 실행 계획을 정리합니다.  
기획, 개발, 데이터, 운영, 보안, 품질 관점에서 빠짐없이 다루는 것을 목표로 합니다.

## 2. 현재 상태 요약
### 이미 갖춘 부분
- 사용자 앱과 관리자 앱 기본 구조
- 예식장, 리뷰, 문의, 가격, 비교, 예산 계산 API
- 공공데이터포털 게이트웨이형 응답을 고려한 수집기 기반 구조
- 샘플 데이터, 시드, 테스트, 빌드 검증

### 아직 부족한 부분
- 실제 공공데이터포털 API URL과 운영 키 연동 자동화
- 검색 고도화
- 지도 기반 반경 필터 정밀화
- 권한 세분화
- 운영자 대량 편집 도구
- 캐시와 비동기 수집 큐

## 3. 고도화 우선순위
### 1단계: 운영 안정화
- PostgreSQL 전용 마이그레이션 체계 정리
- 관리자 권한 검사 미들웨어 추가
- API 응답 로깅과 오류 추적 체계 강화
- 수집 로그의 실패 사유 상세 저장
- 환경별 설정 정리

### 2단계: 데이터 품질 강화
- 주소 정규화 연동
- 좌표 보정
- 전화번호와 주소 기반 중복 탐지 고도화
- 예식장별 데이터 버전 이력 관리
- 운영자 병합 승인 화면 추가

### 3단계: 사용자 경험 강화
- 지도 기반 반경 검색 정교화
- 최근 본 예식장 기반 추천
- 예산 계산기에서 실제 예식장 가격 샘플 반영
- 비교 결과 공유 링크 고도화
- 상세 페이지 성능 개선과 이미지 최적화

### 4단계: 운영 효율화
- Redis 기반 비동기 작업 큐
- 예약 실행 수집 스케줄러
- 관리자 일괄 수정 화면
- 리뷰 스팸 탐지 규칙
- 운영 KPI 리포트 자동 생성

### 5단계: 확장 준비
- 모바일 앱 전환 가능한 BFF 구조 검토
- 검색 엔진 도입 검토
- 결혼 준비 통합 카테고리 확장
- 제휴사 관리 구조
- 광고와 추천 노출 기준 분리

## 4. 세부 실행 계획
### 데이터 영역
- 공공데이터포털 원천별 매핑 표 작성
- 지역별 공공예식장 별도 수집 시나리오 추가
- 수집 결과 검수 대기함 도입

### 백엔드 영역
- 관리자 API에 인증 강제
- OpenAPI 예시 응답 보강
- DTO와 ORM 분리 강화
- AuditLog 조회 API 추가

### 프론트엔드 영역
- 사용자 필터 상태 동기화
- 관리자 편집 폼 검증 강화
- 공통 빈 상태, 오류 상태, 로딩 상태 컴포넌트 확대
- 접근성 라벨과 키보드 탐색 강화

### 테스트 영역
- 관리자 CRUD API 통합 테스트
- 수집기 HTTP 모킹 테스트
- 화면 주요 흐름 E2E 테스트
- 보안 회귀 테스트

## 5. 권장 일정
### 1주차
- 보안 패치와 운영 안정화
- 관리자 인증 보호
- 공공데이터포털 실제 URL 연동 검증

### 2주차
- 주소 정규화와 중복 탐지 고도화
- 수집 실패 이력 상세화

### 3주차
- 사용자 검색과 추천 개선
- 비교 결과 공유 강화

### 4주차
- Redis 큐 도입
- 관리자 대량 편집과 검수 효율화

## 6. 성공 기준
- 실제 공공데이터 수집 성공률 95퍼센트 이상
- 관리자 검수 대기 적체 감소
- 사용자 검색에서 결과 없음 비율 감소
- 예산 계산기 재사용률 증가
- 빌드와 테스트 자동화 안정화
