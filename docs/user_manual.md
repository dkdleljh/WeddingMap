# 사용자 매뉴얼

## 1. 예식장 찾기
1. 홈 또는 탐색 화면으로 이동합니다.
2. 시도, 시군구, 예산, 식대, 분위기 같은 조건을 선택합니다.
3. 결과 목록에서 예식장을 확인합니다.
4. 상세 페이지로 들어가 가격, 교통, 정책, 리뷰를 확인합니다.
5. 마음에 드는 후보는 찜 또는 비교함에 추가합니다.

## 2. 비교함 사용
1. 예식장 카드 또는 상세 화면에서 비교 추가를 누릅니다.
2. 비교함에 2개 이상 후보가 쌓이면 비교 화면으로 이동합니다.
3. 가격, 식대, 주차, 교통, 분위기, 종합 점수를 한 번에 비교합니다.

## 3. 예산 계산기 사용
1. 예상 하객 수와 식사 인원을 입력합니다.
2. 총 예산과 희망 지역, 희망 스타일을 선택합니다.
3. 대관료, 꽃 장식, 추가 옵션 포함 여부를 선택합니다.
4. 예상 총비용 구간과 예산 적합도를 확인합니다.

## 4. 리뷰 작성
1. 리뷰 작성 화면에서 후기 유형을 선택합니다.
2. 제목, 내용, 평점을 입력합니다.
3. 등록 후 관리자의 검수 상태를 기다립니다.

## 5. 문의하기
1. 예식장 상세 화면에서 문의하기를 누릅니다.
2. 이름, 연락처, 메시지, 선호 연락 시간을 입력합니다.
3. 문의 상태는 마이페이지에서 확인합니다.
