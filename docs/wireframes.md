# 와이어프레임 설명

## 1. 홈
- 상단에는 브랜드 로고와 주요 검색 진입을 둡니다.
- 첫 화면에서 제품 가치가 바로 보이도록 시각적 강조 영역을 둡니다.
- 그 아래에는 인기, 추천, 가성비, 공공예식장 섹션을 카드형으로 배치합니다.
- 최근 본 예식장과 하단 탭 바를 유지해 재방문 동선을 짧게 만듭니다.

## 2. 탐색
- 상단은 현재 조건 요약과 필터, 정렬 버튼을 둡니다.
- 중간은 지도 보기와 리스트 보기 전환 영역입니다.
- 결과는 카드형 목록으로 보여 주고, 카드 안에서 찜과 비교 추가를 바로 수행할 수 있게 합니다.

## 3. 상세
- 상단에 대표 사진과 핵심 지표를 둡니다.
- 중간에는 기본 정보, 가격, 홀, 식사, 교통, 정책, 리뷰를 섹션 또는 탭으로 나눕니다.
- 하단에는 문의, 찜, 비교 액션을 유지합니다.

## 4. 비교
- 2개에서 5개 예식장을 가로 비교 테이블로 보여 줍니다.
- 가격, 식대, 주차, 교통, 음식, 분위기, 계약 유연성, 종합 점수를 한 번에 봅니다.
- 상단에는 요약 문구와 공유 확장 포인트를 둡니다.

## 5. 관리자
- 좌측 네비게이션, 우측 콘텐츠 구조를 사용합니다.
- KPI 카드, 표, 상태 변경 버튼, 저장 버튼이 중심입니다.
- 운영자는 클릭 수보다 상태 확인과 수정 속도가 중요하므로 정보 밀도를 일반 사용자 화면보다 높게 둡니다.
