# 정보 구조

## 1. 사용자 앱 1차 메뉴
- 홈
- 탐색
- 상세
- 비교
- 찜
- 마이

## 2. 홈 구조
- 상단 로고
- 검색창
- 지역 빠른 선택
- 인기 예식장 섹션
- 추천 예식장 섹션
- 가성비 추천 섹션
- 공공예식장 섹션
- 큐레이션 카드
- 최근 본 예식장
- 하단 탭 바

## 3. 탐색 구조
- 검색 조건 요약 영역
- 필터 시트 진입 버튼
- 정렬 옵션
- 지도 보기와 리스트 보기 전환
- 카드형 결과 목록
- 빈 결과 안내
- 페이지네이션 또는 무한 로딩

## 4. 상세 구조
- 대표 사진과 핵심 요약
- 기본 정보
- 가격 정보
- 홀 정보
- 식사 정보
- 교통과 주차
- 정책과 계약
- 사진 갤러리
- 리뷰
- 문의하기
- 찜하기
- 비교 추가

## 5. 관리자 구조
- 대시보드
- 예식장 목록
- 예식장 상세 편집
- 가격 관리
- 리뷰 검수
- 문의 관리
- 수집 실행과 로그

## 6. 정보 구조 설계 원칙
- 사용자는 검색과 비교 흐름이 끊기지 않아야 합니다.
- 관리자는 검수와 수정이 한 화면에서 끝나야 합니다.
- 공공데이터와 운영자 입력 데이터가 섞여도 화면 의미가 흔들리지 않아야 합니다.
