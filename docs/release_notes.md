# 릴리스 노트

## 0.1.1
- 관리자 CRUD API 보강
- 관리자 앱의 API 우선 구조 정리
- 관리자 Bearer 토큰 인증 강제
- 관리자 로그인 화면과 세션 저장 구조 추가
- 감사 로그 조회 API와 관리자 감사 로그 화면 추가
- 관리자 인증을 `httpOnly` 쿠키 세션 방식으로 상향
- 사용자 앱의 로그인, 회원가입, 문의, 리뷰, 찜, 비교, 마이페이지 흐름을 API 중심으로 보강
- 예식장 탐색 필터를 URL 쿼리 기반으로 확장
- 사용자 통합 API 테스트 추가
- 공공데이터포털 게이트웨이형 응답 파싱 구조 추가
- SQLite 개발 fallback 정비
- 루트 실행 스크립트 안정화
- Next.js 보안 패치 버전 상향
- 불필요한 중복 테스트와 빌드 산출물 정리
