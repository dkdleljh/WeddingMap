# 요구사항 정의서

## 목적
본 문서는 WeddingMap MVP의 기능 범위, 비기능 요구사항, 데이터 요구사항, 운영 요구사항을 정리합니다.

## 사용자 기능 요구사항
### 홈
- 상단 로고, 검색창, 지역 빠른 선택, 인기, 추천, 가성비, 공공예식장, 큐레이션, 최근 본 예식장 섹션 제공
- 하단 탭 바 제공

### 탐색
- 시도와 시군구 선택
- 지도와 리스트 보기 전환
- 필터 시트와 정렬 옵션
- 카드형 목록과 페이지네이션
- 찜, 비교 추가, 초기화 동작

### 상세
- 기본, 가격, 홀, 식사, 교통, 정책, 리뷰, 사진, 데이터 신뢰도, 운영자 검수 시점 노출
- 문의, 찜, 비교 액션 제공

### 비교
- 2개부터 5개 예식장 비교
- 가격, 보증 인원, 주차, 교통, 음식, 분위기, 계약 유연성, 종합 점수 비교
- 비교 요약 문구와 공유 확장 포인트 제공

### 예산 계산기
- 하객 수, 식사 인원, 지역, 스타일, 총 예산, 옵션 포함 여부 입력
- 예상 총 비용, 식대, 대관료, 옵션비, 예산 적합도, 대안 추천 출력

### 리뷰
- 후기 구분, 항목별 평점, 사진 첨부, 검수 상태, 인증 여부 지원

### 계정
- 회원가입, 로그인, 로그아웃, 내 정보 수정
- 선호 지역, 예산 범위, 하객 수 저장
- 최근 본 예식장, 찜 목록, 비교 이력, 문의 이력, 리뷰 관리 제공

## 관리자 요구사항
- 관리자 로그인과 역할 체크
- KPI 대시보드
- 예식장, 홀, 가격, 식사, 주차, 정책, 사진 관리
- 리뷰 승인 또는 숨김
- 문의 상태 변경
- 수집 실행과 수집 이력 조회
- 중복 후보 확인과 데이터 품질 점검

## 데이터 요구사항
- 공공데이터포털 표준 예식장 데이터를 기초 마스터로 수집
- 서울시 공공예식장 별도 카테고리 분리
- 운영자 입력 데이터와 사용자 리뷰 데이터 병합
- 주소 정규화, 좌표 보정, 중복 탐지, 병합 이력 기록

## 비기능 요구사항
- 모바일 우선 반응형
- 일관된 에러 응답과 로딩 상태 처리
- 검색 성능을 위한 인덱스와 캐시 구조
- 운영 로깅과 감사 로그
- 최소 개인정보 수집과 안전한 비밀번호 해시 처리
- 테스트 가능 구조와 자동화 스크립트 제공
