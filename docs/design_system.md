# 디자인 시스템

## 1. 디자인 목표
- 소비자 서비스답게 직관적이어야 합니다.
- 관리자 화면은 밀도 있게, 사용자 화면은 친절하게 보여야 합니다.
- 모바일 우선으로 설계하되 데스크톱에서도 정보 손실이 없어야 합니다.

## 2. 색상
- 주색상: `#0F766E`
- 강조색: `#F59E0B`
- 사용자 배경: `#F8FAFC`, `#FAFAF9`
- 관리자 배경: `#0C0A09`
- 성공 상태: `#10B981`
- 오류 상태: `#E11D48`

## 3. 타이포그래피
- 기본 글꼴: Pretendard, Noto Sans KR
- 제목: 굵기 700 이상
- 본문: 14px에서 16px
- 보조 텍스트: 12px에서 14px

## 4. 간격 규칙
- 카드 내부 여백: 20px 이상
- 섹션 간격: 24px 이상
- 주요 버튼 높이: 40px 또는 48px
- 모바일에서 터치 영역은 최소 44px 확보

## 5. 공통 컴포넌트
- 예식장 카드
- 필터 시트
- 비교 테이블
- 리뷰 카드
- 상태 패널
- 관리자 KPI 카드

## 6. 상태 표현 원칙
- 로딩 상태는 뼈대 화면 또는 명확한 로딩 문구로 처리합니다.
- 빈 상태는 왜 비어 있는지와 다음 행동을 함께 안내합니다.
- 오류 상태는 재시도 행동을 제시합니다.

## 7. 접근성 원칙
- 텍스트 대비를 확보합니다.
- 버튼과 링크의 역할을 명확히 구분합니다.
- 키보드 탐색이 끊기지 않게 설계합니다.
- 오류 메시지는 폼 필드와 함께 연결해 표시합니다.
