# 사용자 흐름

## 1. 예식장 탐색 흐름
1. 사용자는 홈에서 검색창 또는 지역 빠른 선택을 사용합니다.
2. 탐색 화면에서 시도, 시군구, 예산, 식대, 분위기, 공공 여부 등 필터를 적용합니다.
3. 리스트 또는 지도에서 예식장 카드를 확인합니다.
4. 찜 또는 비교함에 후보를 추가합니다.
5. 상세 화면에서 가격, 교통, 정책, 리뷰를 확인합니다.
6. 예산 계산기와 비교함을 통해 최종 후보를 압축합니다.

## 2. 문의 흐름
1. 사용자는 예식장 상세에서 문의하기를 선택합니다.
2. 이름, 연락처, 메시지, 선호 연락 시간을 입력합니다.
3. 문의가 접수되면 관리자 화면에서 처리 상태를 변경합니다.
4. 사용자는 마이페이지에서 문의 이력을 확인합니다.

## 3. 리뷰 작성 흐름
1. 사용자는 리뷰 작성 화면으로 이동합니다.
2. 방문 후기, 계약 후기, 진행 후기, 하객 후기를 구분해 작성합니다.
3. 평점 항목과 내용을 입력합니다.
4. 등록 후 검수 상태가 대기 중으로 저장됩니다.
5. 관리자가 승인하면 사용자 화면에 노출됩니다.

## 4. 관리자 검수 흐름
1. 관리자는 대시보드에서 미검수 리뷰, 문의 대기 건수, 수집 로그를 확인합니다.
2. 리뷰 검수 화면에서 승인 또는 숨김 처리합니다.
3. 예식장 편집과 가격 관리 화면에서 운영 정보를 갱신합니다.
4. 필요 시 수집 로그 화면에서 공공데이터 수집을 다시 실행합니다.
